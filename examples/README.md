# 示例任务包

这里放**能直接导入、能直接跑**的示例，用来验证自定义任务链路是否正常，
也是写新任务时的参照物。格式规范见 [`../docs/task-file.md`](../docs/task-file.md)。

## demo-screen-scan · 示例·画面体检

```
demo-screen-scan/
  task.json                源文件
  assets/phone.png         大厅左上角的手机图标（用来演示模板点击）
demo-screen-scan-1.0.0.m7atask   打包好的成品，导入这个
```

**导入**：设置 → 数据 → 导入任务包 → 选 `.m7atask`（会先弹免责声明，倒计时结束才能点同意）

**执行**：任务列表加一个「自定义任务」→ 卡片里选「示例·画面体检」→ 开始。
建议站在**游戏大厅**跑。

**它依次做什么**

| 步骤 | 演示的原语 | 会不会动到游戏 |
| --- | --- | --- |
| ① | `ifTemplate` 模板识别手机图标 | 不会 |
| ② | `ifCount` 全屏数金色块（`#FFC870`），"数星星"的通用写法 | 不会 |
| ③ | `setVar` + `ifExpr`：算 `(2+3)*4`、`len()`、`clamp()` | 不会 |
| ④ | `repeat` 循环 3 次 | 不会 |
| ⑤ | `whileExpr` 循环 + 变量自增 | 不会 |
| ⑥ | `readText` OCR 读左上角文字并存进变量 | 不会 |
| ⑦ | `assertCount` **故意写成必失败**，验证 `optional: true` 只跳过不中断 | 不会 |
| ⑧ | `waitColor` 等颜色（超时也只跳过） | 不会 |
| ⑨ | `tapTemplate` 点手机图标 | **会**（弹出手机菜单） |

最后会点一下左侧空白把菜单关掉；如果菜单还开着，手动点一下空白即可。

**怎么看结果**

跑完看日志，按顺序应该能看到 `✅ ①②③④⑤` 这几行。有任何 `❌` 说明对应环节有问题，
把整段日志贴出来即可。

## 自己做一个

1. 复制 `demo-screen-scan/task.json`，改 `id` / `name` / `author`；
2. 把手机截图裁成小图（**只裁按钮本身**，别把周围 UI 裁进去）放进 `assets/`；
3. `{"op": "tapTemplate", "image": "assets/你的按钮.png"}`；
4. 打包：`task.json` 放 zip 根目录，图片放 `assets/` 下，扩展名改 `.m7atask`。

模板别从 PC 版截 —— 分辨率差 1.4 倍以上，单尺度匹配基本不会命中（这是本项目踩过的坑）。
