## 0.6.0beta

### 兑换码

- 新增「兑换码」任务：把站点上的码一次兑完，不用一个个手打
- 清单不写死在 APK 里，每次执行前从站点 `codes.md` 拉取；站点加码后下次执行就能看到，不需要发版
- 分组展示（版本福利 / 前瞻直播 / 社群福利…），限时码带倒计时，过期自动跳过
- 支持自定义码：自己收集的码填进面板，和站点码一起兑
- 已兑换、已使用的码记在本地，后续不再重复输入
- 兑换链路：识别大厅头像 → 手机 → 「…」→ 兑换码 → 写剪贴板 → 点粘贴 →（游戏的「请求从剪切板粘贴」提示）→ 确认 → 读结果

### 日志瘦身

- 调试截图由 PNG 改为 JPEG（质量 85），单张从 1.5~2.3 MB 降到几百 KB
- 单次任务最多保留最近 60 帧，环形覆盖；导出日志包最多 80 张
- 启动时清理历史遗留的 PNG 帧。之前一轮任务能写出 300 MB 以上的日志包，现在通常几十 MB

### 修复

- 修复任务参数拼装少了右括号，导致内核解析不到兑换码清单、任务直接跳过的问题（改用 `buildJsonObject` 构造）
- 修复关闭界面时返回键点击位置偏移 33px，部分机型关不掉弹窗
- 关闭界面、打开手机菜单不再固定等待，命中特征就继续，整轮任务更快
- 站点侧：识别 Cloudflare Pages 对缺失路径返回首页 HTML 的行为，拉取失败时不再当成有效内容解析

## 安装说明

- 需要 **Shizuku** 或 **Root**
- 额外权限：悬浮窗、通知、后台运行不受限（设置 → 电池 → 不限制）
- 同一签名，可直接覆盖安装旧版本
- 游戏需已登录并停在大厅
- 兑换码清单在站点上维护，格式见 `docs/CODES.md`
