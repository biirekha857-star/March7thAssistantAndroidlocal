### 新增 · 自定义任务（任务包）

第三方作者可以写一份 `.m7atask` 交给用户导入，跑起来和内置任务没有区别。

- 入口：设置 → 数据 → **导入任务包**；同页可看「已安装任务包」「在线任务包」和《任务文件开发规范》
- 任务文件是**动作清单**而不是代码：24 种动作原语（模板匹配、OCR 取字、取色、区域判断、
  点击/长按/滑动、条件分支、循环、等待、变量、表达式）
- 执行器只持有三样东西：注入点击、截屏识别、日志回调 —— 没有 `startActivity`、没有 `packageManager`、
  没有网络栈。所以任务包**能操作屏幕，但不能执行代码、装应用、联网、读包外文件**
- 预算闸门：单次 ≤5000 步 / ≤20 分钟，嵌套 ≤4 层，重复 ≤20 次，模板资源路径运行期二次校验
- 导入链路：内存解压 → 全量校验（最多列 12 条错）→ staging 目录 → rename 落盘；校验失败不落盘
- **导入前强制阅读 8 秒免责声明**：内容来自网络，安全性/合法性未审核，损失由使用者承担
- 在线分发：站点 `taskpacks/index.json` 由 ECDSA P-256 签名，包体校验 sha256 + size；公钥内置 APK

### 新增 · 忘却之庭（混沌回忆）

- 导航链路：手机 → 星际和平指南 → 逐光捡金 → 忘却之庭 → 混沌回忆 → 传送
- 进页后先读本期进度（`x/36`），已满星直接收工
- 关卡栏会自己横向滑动找层号（OCR 三级匹配：`07` / 含 `07` / `7`），视口只显示 4 层也能找到
- 逐层判断星数：按金色连通块计数（模板 17×17、实机 40×40，模板匹配不可用），满 3 星跳过
- 进战斗自动点开「自动战斗」，结算出现「返回忘却之庭」即判结束，随后领奖、关明细、回大厅
- **不自动选人**：直接用游戏里已按层保存好的队伍（手游选人要滚 19 行列表，收益与风险不成比例）
- 配置项：起始层 / 结束层（默认 7~12）、跳过满星层、自动战斗、单层超时

### 修复 · 星际和平指南判不出来

原来「画面变化 → 做一次 OCR → 立刻把基准帧换成当前帧」：如果那一次正好踩在淡入过渡帧上返回 null，
之后画面静止 `frameChanged` 恒为 false，就再也不会复查，20 秒后报「指南页未打开」。

现在改为：变化后开 2 秒观察窗，窗内每轮都判；窗过后每秒强制复查一次。

### 修复 · 每日实训活跃度读不到

OCR 区域 `(0.10, 0.18, 0.10, 0.10)` 只框住火焰图标下半圈，数字被切在框外，永远返回「活跃度未读到」。
实测数字在 `x[227,282] y[315,347]`，区域改为 `x[211,384] y[302,389]`，并补 3 次重试与 `O→0`、`l→1` 容错。

### 修复 · 委托派遣误判

点击「派遣」后画面约 840ms 才切换，固定等 1 秒再 OCR 容易踩在过渡帧上误判「未派遣」。
改为 3 次重试 + 间隔 700ms。

### 修复 · 清体力「快捷补充开拓力」开关永远不点

两个问题叠加：

- 模板 `power/switch_off.png` 是 PC 端导出的 83×43，实机只有 59×30。多尺度缩到 0.71 后边缘糊掉，分数过不了阈值
- 搜索区左边界 `0.88 × 1920 = 1690`，正好压在开关右边缘（实机 `x[1631,1689]`），整块只落进 1 列像素

模板换成真机同源截图裁出的 59×30，区域改为 `x 0.80~0.95 / y 0.62~0.76`，判定简化为：**看到关闭态就点一下，看不到就不动**。

## 安装说明

- 需要 **Shizuku** 或 **Root**
- 额外权限：悬浮窗、通知、后台运行不受限（设置 → 电池 → 不限制）
- 同一签名，可直接覆盖安装旧版本
- 游戏需已登录并停在大厅
- 使用忘却之庭前，请先在游戏里为该期每一层配好队伍
- 任务包从提权进程读取，App 导入后会在每次任务下发前投递到 `/data/local/tmp/maameow/taskpacks/`；
  换 `coreDataLocation` 设置不需要重新导入
