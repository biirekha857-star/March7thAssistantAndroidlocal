## 0.5.7beta

### 界面重构

- 首页与后台任务页合并为「首页」，底部导航精简为 **首页 / 定时 / 设置**
- 任务列表改为卡片流，点开即在原位调参，不再跳转半屏面板
- 日志改为时间线样式，按级别着色
- 设置改为分类式，与手机系统设置一致

### 修复

- 修复进入主界面必然崩溃的问题：任务卡片展开时内层滚动容器收到无限高度约束
- 修复每日首次上线领不到列车补给（月卡）的问题：改为先探弹窗再判大厅，补上奖励确认界面，点击避开界面敏感区
- 修复清体力点击无效、导航到生存索引失败时只能干等数分钟的问题
- 修复指南页误判，主界面被当成指南页导致乱点
- 修复清体力失败时副本名显示为空（「副本「」」）
- 修复注入失败只写「down 失败」的问题，现在会记录异常原因、注入模式与窗口焦点现场

### 改进

- 移除无障碍服务（原本只用于音量键快捷键），运行态改用「边框 + 悬浮球」呼出控制
- 新增触控自愈：注入失败自动清理残留手势并降级重试，连续失败直接熔断，不再空转数分钟
- 新增退出确认兜底：按过返回键后自动检测「是否退出游戏」并点取消，避免任务卡死在确认框
- 新增应用内更新提示：弹窗里直接显示本页的更新要点，点「立即更新」跳转下载

## 0.5.6beta（上一版，一并补上）

- 修复部分机型（实测荣耀 MagicOS）游戏画面被放大裁切、「点击进入」一直不出现的问题：50 秒未命中时自动做一次主屏往返，逼系统重算虚拟屏缩放
- 画面自愈时发通知说明情况，任务继续跑完，不再静默
- 首页标题由「M7A」改为完整名称 **March7thAssistant**；修正主题说明（关闭莫奈主题后是金色而非蓝色）
- 修复 OCR / 模板匹配中的多处 Mat 未释放（全屏 OCR 会持续占用整帧内存）
- 修复 `am` 调用无超时导致看门狗被永久阻塞；冷启动前用 `pidof` 确认进程退出，必要时补 `kill -9`
- 定时任务不再强制把 App 拉到前台；日志包新增 `diag/` 系统现场快照（窗口 frame、SurfaceFlinger 变换、input viewport）

## 安装说明

- 需要 **Shizuku** 或 **Root**
- 额外权限：悬浮窗、通知、后台运行不受限（设置 → 电池 → 不限制）
- 同一签名，可直接覆盖安装旧版本
- 游戏需已登录并停在大厅
