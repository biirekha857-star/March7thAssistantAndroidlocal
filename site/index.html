核心功能

基于虚拟屏技术，真正意义上的后台运行

🖥️

虚拟屏后台运行

游戏跑在独立虚拟显示器上，你可以同时刷视频、聊天、看文档，完全不被打断。

⚡

清体力

拟造花萼（金/赤）、凝滞虚影、侵蚀隧洞、饰品提取、历战余响，全部支持，自动连打。

📋

每日实训

勾选今天要做的项目，委托、拍照、合成机、秘技、消耗体力，做完自动领奖。

🎯

离线识别

OpenCV 模板匹配 + PP-OCRv6 本地推理，不需要联网，不需要上传任何数据。

🔗

任务链编排

拖拽排序、自由组合，支持定时执行。早上自动跑完，起床直接上号。

🛡️

无需 Root

支持 Shizuku 授权，不用解锁、不用改系统，普通用户也能用。

三步开始

下载后 2 分钟就能跑起来

1

安装并授予权限

安装 APK，按引导授予 Shizuku 或 Root 权限

2

勾选要做的任务

在「任务」页选择邮件、清体力、每日实训等，可拖拽排序

3

点击开始

游戏会自动启动到虚拟屏，完成后自动关闭

⚠️ 使用前请务必了解

  • 自动化操作存在账号风险，请自行评估后使用
  • 请勿在米游社等官方社区讨论或宣传本项目
  • 本项目完全免费开源，付费获取的都是骗子
  • 建议关闭游戏的省电优化，避免后台被杀
  • 遇到问题请附上日志压缩包：设置 → 日志 → 导出
