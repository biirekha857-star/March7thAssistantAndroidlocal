Features

它能把每天的重复劳动全接过去

从启动游戏到关掉游戏，中间那些「每天都要点一遍」的流程，交给它跑完就行。

界面重构

首页与任务页合并，底部导航精简为 首页 / 定时 / 设置。任务改成卡片流，点开就地调参。

0.5.7beta 全新排版

虚拟屏后台运行

游戏跑在独立虚拟显示器上，手机照常刷视频、回消息，任务在后台自己跑完。

不影响日常使用

清体力

拟造花萼（金 / 赤）、凝滞虚影、侵蚀隧洞、饰品提取、历战余响，按预设次数刷完为止。

支持 6 类副本

每日实训

委托、拍照、合成机、秘技、消耗体力、领取奖励，勾选哪项跑哪项。

勾选式执行

一键日常

启动游戏 → 跳过公告 → 领邮件 → 清体力 → 每日实训 → 关闭游戏，全流程无人工干预。

可定时执行

触控自愈

注入失败会自动清理残留手势并降级重试；按过返回键后检测「是否退出游戏」并点取消，不会卡死。

不用无障碍服务

Get Started

三步开始

不需要刷机，也不需要写配置。装好、给权限、点一下。

01

安装并授予权限

安装 APK 后，按引导授予 Shizuku 或 Root 权限。

02

关掉省电限制

在系统设置里关闭本应用的省电优化，否则后台任务会被系统掐断。

03

游戏停在大厅

确认游戏已登录并停在大厅，回到 App 选好任务点开始即可。
